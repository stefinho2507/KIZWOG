# Dortmund Schnellrechner – Wohngeld & Kinderzuschlag

Mobile-first Schnellcheck für eine **unverbindliche Schätzung** von Wohngeld und Kinderzuschlag in Dortmund.

## V2: bewusst schnell
Die Startansicht fragt nur nach Erwachsenen, Kindern, Bruttokaltmiete, Warmmiete und Netto-Einkommen. Brutto sowie Unterhalt/Kindeseinkommen sind optional unter „genauer“.

- keine Installation / kein Backend
- keine Speicherung oder Übertragung persönlicher Daten
- direkt für GitHub Pages geeignet
- Dortmund: Mietenstufe III
- Wohngeld: Formel nach § 19 WoGG mit Tabellenwerten, Heizkosten- und Klimakomponente
- Kinderzuschlag: vereinfachte Orientierung, max. 297 € je Kind; keine amtliche Berechnung

## GitHub Pages
Dateien in ein Repository hochladen → **Settings → Pages** → Branch `main` / Root auswählen.

## Hinweis
Das Tool ersetzt weder Wohngeldbehörde noch Familienkasse und ist keine Rechtsberatung. Gerade die Einkommensbereinigung kann das Ergebnis verändern.
